How to compress an image for WhatsApp

WhatsApp and similar apps often shrink photos on send, and very large camera files can be slow to attach. Compressing a copy first gives you more control over quality, and it helps when you send the file as a document so the recipient can keep a sharper version.

Steps

  1. Open Free Image Compressor. Add the JPG, PNG, or WebP file from your phone or computer. The image is compressed in the browser.
  2. Pick a format and quality. JPEG or WebP usually shrinks photos more than PNG. Start with a moderate quality setting, then download a preview.
  3. Compare the result. Check faces, text in the picture, and any fine lines. If the file is still large, lower the quality a little or resize the longest edge first.
  4. Send the compressed copy. Attach the new file in WhatsApp. If you need the recipient to get this exact file, send it as a document rather than as a camera photo, when the app allows that.

Keep the original

Compression is not always reversible. Save the original camera file and share a copy.

Chat apps may compress again

Even a prepared file can be recompressed when you send it as a regular photo. That is a limit of the chat app, not of this tool.
